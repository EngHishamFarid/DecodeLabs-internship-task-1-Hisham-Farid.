# To-Do List Manager

## Description
A simple Python command-line application that helps users manage their daily tasks by adding, viewing, and deleting tasks.

## Features
- View all tasks
- Add new tasks
- Delete completed tasks
- Interactive menu system

## Technologies Used
- Python
- Lists
- Loops
- Conditional Statements

## How to Run
1. Make sure Python is installed.
2. Download the project files.
3. Open terminal in the project folder.
4. Run:
python main.py
